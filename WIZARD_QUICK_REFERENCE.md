# 🎯 Consultation Wizard - Quick Reference Card

## For Doctors Using the AI-EMR System

---

## 🚀 How to Start a Consultation (3 Simple Ways)

### Method 1: From Today's Queue ⭐ RECOMMENDED
```
Dashboard → Find patient in "Today's Schedule" → Click green ▶ button
```

### Method 2: Quick Actions
```
Dashboard → "Guided Consultation" card (featured) → Select patient
```

### Method 3: Direct URL
```
/doctor/consultation-wizard?patient_id=123&appointment_id=456
```

---

## 📋 The 5 Steps (Cheat Sheet)

### Step 1️⃣: Patient Prep (10 seconds)
**What to do:**
- ✅ Glance at patient info
- ✅ Read AI case summary
- ✅ Check risk badge
- ✅ Click **"I'm Ready →"**

**Keyboard:** `Ctrl + →` to advance

---

### Step 2️⃣: Recording (2-5 minutes)
**What to do:**
1. Click **"Start Recording"** (red button)
2. Allow microphone access
3. Talk with patient normally
4. Watch live transcription appear
5. Click **"Stop & Analyze →"** when done

**Keyboard:** `Esc` to exit (if needed)

---

### Step 3️⃣: AI Review (30 seconds)
**What to do:**
- ⏳ Wait for AI processing (2-3 seconds)
- 📝 Review 7 auto-filled clinical fields
- ✏️ Edit any incorrect data
- Click **"Chart Looks Good →"**

**Fields AI fills:**
1. Symptoms
2. Medical History
3. Physical Findings
4. Medications
5. Vital Signs
6. Preliminary Diagnosis
7. Care Plan

---

### Step 4️⃣: Diagnosis (30 seconds)
**What to do:**
- 📝 Review AI-suggested diagnosis
- ✏️ Edit if needed
- 🏷️ Click ICD-10 tags to add codes
- 🔘 Select consultation type
- Click **"Save Diagnosis →"**

**ICD-10 Quick Add:**
- Just click any tag (e.g., `J06.9`, `J18.9`)
- Code inserts into diagnosis automatically

---

### Step 5️⃣: Complete (15 seconds)
**What to do:**
- ✅ Review consultation summary
- ☑️ Check desired follow-up actions:
  - Schedule follow-up? (pick date)
  - Prescribe medications?
  - Order lab tests?
  - Send summary to patient? (recommended)
- Click **"Complete Appointment ✓"** (green button)

**Done!** 🎉 Redirects to dashboard

## ⚠️ Important Notes

### ✅ DO:
- Review AI-filled data carefully
- Add ICD-10 codes for billing
- Schedule follow-ups before completing
- Send summary to patient (improves satisfaction)

### ❌ DON'T:
- Skip reviewing the AI chart
- Forget to edit incorrect data
- Leave diagnosis blank (required)
- Close browser during recording

---

## 🆘 Troubleshooting

### Microphone not working?
1. Allow microphone access in browser
2. Ensure HTTPS connection
3. Try Chrome browser
4. Close other apps using mic

### AI analysis failed?
- You can still manually enter data
- All clinical chart fields are editable
- Not a blocker - proceed manually

### Need to exit?
- Click ❌ button (top right)
- Press `Esc` key
- Confirmation if unsaved progress
